Cara Deploy Gratis ke Netlify

Web app ini dirancang sebagai **Single Static File** sehingga sangat mudah dipublish ke Netlify tanpa butuh server/build step.

  1. Simpan file ini dengan nama index.html.
  2. Buka browser dan masuk ke Netlify Drop (app.netlify.com/drop).
  3. Seret (drag & drop) berkas index.html atau folder tempat file tersimpan ke area upload Netlify.
  4. Netlify akan langsung memberikan link URL publik gratis (misal: https://galeri-keluarga.netlify.app).
